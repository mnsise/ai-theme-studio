# AI Theme Studio — راهنمای نصب و استفاده

افزونه‌ای برای ساخت وب‌سایت کامل، سئومحور و **کاملاً قابل‌ویرایش در المنتور** از روی توضیح متنی و تصاویر مرجع.
خروجی، صفحات و قالب‌های بومی المنتور (Flexbox Container و ویجت‌های استاندارد) است؛ نه HTML ثابت یا اسکرین‌شات.

## پیش‌نیازها

| مورد | حداقل | توضیح |
| --- | --- | --- |
| PHP | 8.0 | روی 8.0، 8.2 و 8.5 تست شده است. |
| وردپرس | 6.3 | روی 7.1.3 تست شده است. |
| المنتور (رایگان) | 3.16 | روی 4.3.5 تست شده است. Flexbox Container توصیه می‌شود. |
| المنتور پرو | اختیاری | فقط برای Theme Builder (هدر/فوتر سراسری). |
| Permalink | توصیه: «نام نوشته» | برای نشانی‌های تمیز و سئو. |

بدون المنتور، افزونه فعال می‌شود، پروژه ذخیره می‌شود و تنظیمات کار می‌کند، اما **تولید سایت با پیام روشن رد می‌شود** (هیچ صفحه نیمه‌کاره‌ای ساخته نمی‌شود).

## نصب

1. پوشه `ai-theme-studio` را در `wp-content/plugins/` قرار دهید (یا فایل zip را از «افزونه‌ها › افزودن» بارگذاری کنید).
2. افزونه را فعال کنید. جدول‌های `wp_ats_jobs`، `wp_ats_artifacts` و `wp_ats_logs` ساخته می‌شوند.
3. از منوی «استودیو قالب › تنظیمات» ارائه‌دهنده هوش مصنوعی و کلید API را وارد و «آزمایش اتصال» را بزنید.
4. «استودیو قالب › وضعیت سیستم» را بررسی کنید (نسخه المنتور، Container، افزونه سئو، WP-Cron).

> پوشه‌های `vendor/`، `tests/`، `node_modules/` و فایل‌های `composer.*`/`package.json` فقط برای توسعه‌اند و در بسته انتشار لازم نیستند.

## ارائه‌دهندگان هوش مصنوعی

| ارائه‌دهنده | تصویر (Vision) | خروجی JSON | نکته |
| --- | --- | --- | --- |
| OpenAI | بله (gpt-4o و مشابه) | `response_format: json_object` | پیش‌فرض |
| Anthropic | بله (Claude 3+) | از طریق دستور و استخراج JSON | |
| Google Gemini | بله | `responseMimeType: application/json` | |
| OpenAI-compatible | بستگی به مدل | اختیاری | برای OpenRouter، سرور محلی و… (فقط HTTPS) |

- تنظیم «Vision» روی `auto` بر اساس نام مدل تشخیص می‌دهد؛ اگر مدل تصویر را پشتیبانی نکند، **تحلیل تصویر انجام نمی‌شود و این موضوع صریحاً در پروژه گزارش می‌شود** (هیچ تحلیل ساختگی تولید نمی‌شود). در این حالت فقط نقش و توضیحی که خودتان برای تصویر نوشته‌اید استفاده می‌شود.
- کلید API رمزنگاری‌شده (AES-256-CBC همراه با HMAC-SHA256، با کلید مشتق از salt‌های وردپرس) ذخیره می‌شود و در رابط کاربری فقط ۴ کاراکتر آخر نمایش داده می‌شود.
- برای عدم ذخیره کلید در پایگاه‌داده، در `wp-config.php` تعریف کنید:

```php
define( 'ATS_API_KEY', 'sk-...' );
define( 'ATS_PAGESPEED_API_KEY', '...' ); // اختیاری
```

### چه داده‌ای به ارائه‌دهنده ارسال می‌شود؟

فقط: توضیح پروژه، تنظیمات طراحی، اطلاعات کسب‌وکاری که خودتان در فرم وارد کرده‌اید، و تصاویر مرجع (فقط اگر مدل از تصویر پشتیبانی کند).
**ارسال نمی‌شود:** کلیدهای API، کاربران، ایمیل مدیر، محتوای دیگر صفحات، تنظیمات وردپرس یا اطلاعات سرور.

## روند کار

1. **پروژه جدید:** توضیح (۲۰ تا ۸۰۰۰ نویسه)، زبان/جهت، نوع کسب‌وکار، رنگ، فونت، سبک، تراکم، صفحات موردنیاز و اطلاعات تماس.
2. **تصاویر:** تا ۱۰ تصویر (JPG/PNG/WebP، پیش‌فرض حداکثر ۸ مگابایت؛ برای تحلیل، نسخه‌ای با ضلع حداکثر ۱۲۸۰ پیکسل و بدون EXIF ارسال می‌شود) با نقش: لوگو، الهام طراحی، اسکرین‌شات، محصول، تیم، hero، گالری و… .
3. **تولید:** تحلیل نیازها › تحلیل تصاویر › نقشه سایت › (بازبینی و تأیید نقشه سایت) › سیستم طراحی › محتوای صفحات › ساخت اسناد المنتور › کنترل کیفیت.
   پیشرفت زنده نمایش داده می‌شود؛ قابل لغو و ادامه است و در صورت خطای موقت ارائه‌دهنده (429/5xx) تا ۳ بار با تأخیر تکرار می‌شود.
4. **بازبینی:** صفحات به‌صورت **پیش‌نویس** ساخته می‌شوند. پیش‌نمایش، ویرایش در المنتور، بازتولید صفحه یا یک بخش، و بازگردانی نسخه‌های قبلی.
5. **منو:** پیش‌نمایش ساختار منو و ساخت/به‌روزرسانی منوی خود افزونه. منوی موجود در جایگاه‌های قالب **بدون اجازه صریح جایگزین نمی‌شود**.
6. **انتشار:** فقط با تأیید صریح. گزینه‌ها: صفحه اصلی، صفحه ۴۰۴، اعمال سبک‌های سراسری المنتور (با نسخه پشتیبان) و Theme Builder (فقط پرو).

## سئو

- دقیقاً یک H1 در هر صفحه و بدون پرش سطح عنوان (اعتبارسنجی پیش از ذخیره و در ممیزی).
- عنوان و توضیحات متا: اگر Yoast، Rank Math، SEOPress یا The SEO Framework فعال باشد، در فیلدهای همان افزونه نوشته می‌شود (فقط اگر خالی باشد یا مقدار قبلی خود این افزونه باشد) و **خروجی تکراری در `<head>` چاپ نمی‌شود**. AIOSEO API نوشتن عمومی ندارد؛ مقادیر در گزارش سئو برای کپی نمایش داده می‌شود.
- JSON-LD فقط با داده‌های واقعی: `Organization` (نام، لوگو و اطلاعات تماسی که خودتان وارد کرده‌اید)، `WebSite` و `BreadcrumbList`. وقتی افزونه سئو فعال است، این خروجی چاپ نمی‌شود. امتیاز، نظر مشتری یا مدرک ساختگی تولید نمی‌شود.
- پیوند داخلی بین صفحات، بدون صفحه یتیم؛ صفحه ۴۰۴ `noindex` است.

## محدودیت‌های شناخته‌شده

- **امتیاز Lighthouse توسط افزونه تضمین یا جعل نمی‌شود.** ممیزی داخلی فقط پیش‌بررسی ایستا است (DOM تخمینی، عمق تودرتویی، فونت‌ها، تصاویر). اندازه‌گیری واقعی با PageSpeed Insights (در افزونه، برای صفحات منتشرشده) یا [Lighthouse CI](LIGHTHOUSE.md) انجام می‌شود. سرعت نهایی به هاست، کش، قالب فعال و افزونه‌های دیگر بستگی دارد.
- **بدون المنتور پرو:** هدر و فوتر به‌صورت قالب‌های المنتور ساخته می‌شوند و فقط روی صفحات تولیدشده (با قالب Canvas) نمایش داده می‌شوند. نوشته‌های بلاگ و بایگانی‌ها از قالب فعال وردپرس استفاده می‌کنند.
- **فرم تماس:** اگر Contact Form 7 یا WPForms نصب باشد، اولین فرم موجود با ویجت Shortcode درج می‌شود؛ در غیر این صورت صفحه تماس با ایمیل/تلفن/نشانی واردشده (یا یک متن نمونه که صریحاً «نمونه» علامت خورده) ساخته می‌شود. فرم غیرکاربردی ساخته نمی‌شود. ویجت Form المنتور پرو در این نسخه استفاده نمی‌شود.
- **تصاویر:** افزونه تصویر تولید نمی‌کند و فقط از تصاویر بارگذاری‌شده استفاده می‌کند. ارجاع به تصویری که وجود ندارد در اعتبارسنجی حذف می‌شود؛ تصویر یا لینک خارجی ساخته نمی‌شود.
- **AIOSEO:** فقط گزارش مقادیر پیشنهادی (بالا).
- **WP-Cron:** اگر `DISABLE_WP_CRON` فعال باشد، تا زمانی که صفحه پروژه باز است، مرورگر مراحل را جلو می‌برد. برای اجرای پس‌زمینه یک کران واقعی سرور تنظیم کنید.
- کیفیت محتوا به مدل انتخابی بستگی دارد؛ همه خروجی‌ها اعتبارسنجی می‌شوند، اما بازبینی انسانی متن (به‌خصوص ادعاهای حقوقی، قیمت‌ها و اطلاعات تماس) ضروری است.

## عیب‌یابی

| مشکل | علت محتمل / راه‌حل |
| --- | --- |
| «کلید API تنظیم نشده» | در تنظیمات کلید را وارد و «آزمایش اتصال» را بزنید. |
| «المنتور فعال نیست» | Elementor را نصب/فعال کنید؛ وضعیت سیستم را ببینید. |
| پیشرفت متوقف می‌ماند | WP-Cron غیرفعال یا مسدود است؛ صفحه پروژه را باز نگه دارید یا کران سرور تنظیم کنید. پس از ۵.۵ دقیقه قفل منقضی و کار ادامه می‌یابد. |
| خطای 429 / محدودیت نرخ | محدودیت ارائه‌دهنده یا «حداکثر درخواست در ساعت» در تنظیمات. چند دقیقه بعد «ادامه» بزنید. |
| «خروجی مدل با ساختار مطابقت نداشت» | مدل JSON معتبر برنگردانده (پس از یک بار اصلاح خودکار). مدل قوی‌تر یا `max_output_tokens` بیشتر را امتحان کنید. |
| خروجی کوتاه/ناقص | `max_output_tokens` را افزایش دهید (پیش‌فرض ۸۰۰۰). |
| صفحات به‌صورت Section/Column | Flexbox Container در المنتور › تنظیمات › ویژگی‌ها غیرفعال است. |
| هدر/فوتر روی صفحات دیگر نیست | بدون المنتور پرو انتظار می‌رود (بخش محدودیت‌ها). |
| بازتولید پیام «ویرایش شده» می‌دهد | صفحه یا بخش را در المنتور ویرایش کرده‌اید؛ با تأیید، نسخه پشتیبان ذخیره و سپس جایگزین می‌شود. |
| تکرار متای سئو | باید رخ ندهد؛ «وضعیت سیستم › افزونه سئو» را بررسی و در صورت نیاز «خروجی متای سئو» را در تنظیمات خاموش کنید. |

گزارش رخدادها در «پروژه › تاریخچه» و جدول `wp_ats_logs` (۳۰ روز نگهداری) است.

## حذف افزونه

به‌صورت پیش‌فرض داده‌ها نگه داشته می‌شوند. اگر «حذف داده‌ها هنگام حذف افزونه» را فعال کنید، جدول‌ها، پروژه‌ها و تنظیمات حذف می‌شوند.
**صفحات، منوها، رسانه‌ها و قالب‌های المنتور ساخته‌شده، محتوای سایت شما هستند و هرگز حذف نمی‌شوند.**

## Hookها برای توسعه‌دهندگان

| Hook | نوع | کاربرد |
| --- | --- | --- |
| `ats_ai_provider` | filter | جایگزینی ارائه‌دهنده با پیاده‌سازی `ProviderInterface` (مثلاً پراکسی سازمانی). |
| `ats_prompt_template` | filter | تغییر قالب‌های پرامپت `prompts/*.md`. |
| `ats_capability` | filter | تغییر سطح دسترسی هر عملیات. |
| `ats_allow_non_uploaded_file` | filter | فقط برای تست؛ در محیط واقعی فعال نکنید. |
